### 1. 简介

UIScriptAutoGenTool 是一个强大的 Unity 编辑器扩展工具，旨在自动化 UI 脚本的创建和管理过程。通过该工具，您可以：

- 快速创建标准化的 UI Controller 和 UI Task 脚本
- 自动绑定 UI 组件到脚本变量
- 管理复杂 UI 层次结构的组件引用
- 减少手动编写样板代码的工作量

---

### 2. 安装与设置

#### 2.1 环境要求
- Unity 2018.4 或更高版本
- BJFramework 框架支持

#### 2.2 工具访问路径
1. 打开 Unity 编辑器
2. 在顶部菜单栏选择 `BJFramework` → `UIScriptAutoGenTool`
3. 工具窗口将在编辑器中打开

---

### 3. 快速入门

#### 3.1 基本工作流程
1. **选择 UI Prefab**：在基础模块中选择要处理的 UI Prefab
2. **创建 Controller**：使用 Controller 创建模块生成 UI Controller 脚本
3. **绑定组件**：在组件绑定模块中将 Prefab 中的组件绑定到 Controller
4. **创建 Task**：使用 Task 创建模块生成 UI Task 脚本
5. **绑定 Task**：在 Task 绑定模块中将 Controller 和 Prefab 关联到 Task

#### 3.2 简单示例
假设您有一个名为 "MainMenu" 的 UI Prefab，以下是如何为它创建完整脚本结构：

1. 打开 UIScriptAutoGenTool
2. 在基础模块中选择 "MainMenu" Prefab
3. 切换到 Controller 创建模块，创建 "MainMenuController"
4. 切换到组件绑定模块，添加按钮、文本等组件
5. 切换到 Task 创建模块，创建 "MainMenuTask"
6. 切换到 Task 绑定模块，将 Controller 和 Prefab 关联到 Task

### 4. 功能模块详解

#### 4.1 基础模块

**功能**：选择和管理 UI Prefab，加载和保存配置数据。

**操作步骤**：
1. 在工具窗口顶部选择 "基础" 选项卡
2. 点击 "选择Prefab" 按钮，在弹出的窗口中选择目标 Prefab
3. 工具会自动加载相关的 JSON 配置文件（如果存在）

**注意事项**：
- 确保选择的 Prefab 包含您需要绑定的 UI 组件
- 如果是首次使用，工具会创建新的配置文件

#### 4.2 Controller 创建模块

**功能**：创建和管理 UI Controller 脚本。

**操作步骤**：
1. 切换到 "Controller创建" 选项卡
2. 在 "脚本挂载点" 字段中指定 Controller 脚本的挂载位置
3. 输入脚本名称（通常以 "Controller" 结尾）
4. 添加脚本描述（可选）
5. 点击 "创建脚本" 按钮

**生成结果**：
- 在指定路径下创建新的 C# 脚本文件
- 脚本包含标准化的 Controller 结构和基础方法

#### 4.3 组件绑定模块

**功能**：将 Prefab 中的 UI 组件绑定到 Controller 脚本。

**操作步骤**：
1. 切换到 "组件绑定" 选项卡
2. 在 "选择组件" 字段中，从场景中选择 Prefab 实例中的组件
3. 从下拉列表中选择要绑定的组件类型
4. 输入自定义变量名（可选，不输入则使用默认命名）
5. 点击 "添加组件" 按钮
6. 重复步骤 2-5 添加更多组件
7. 完成后点击 "生成代码到脚本" 按钮

**功能特性**：
- 支持多种 UI 组件类型（Button, Image, Text, Toggle 等）
- 自动计算组件相对路径
- 支持自定义变量命名
- 自动检测变量名冲突

#### 4.4 Task 创建模块

**功能**：创建和管理 UI Task 脚本。

**操作步骤**：
1. 切换到 "Task创建" 选项卡
2. 输入 Task 名称（通常以 "Task" 结尾）
3. 添加 Task 描述（可选）
4. 点击 "创建脚本" 按钮

**生成结果**：
- 在指定路径下创建新的 C# 脚本文件
- 脚本包含标准化的 Task 结构和基础方法

#### 4.5 Task 绑定模块

**功能**：将 Controller 和 Prefab 关联到 Task 脚本。

**操作步骤**：
1. 切换到 "Task绑定" 选项卡
2. 在 "选择Prefab" 字段中选择要关联的 Prefab
3. 在 "选择Controller" 字段中选择要关联的 Controller
4. 如果需要绑定按钮事件，选择按钮和对应的事件处理函数
5. 点击 "添加绑定" 按钮
6. 重复步骤 2-5 添加更多绑定
7. 完成后点击 "生成代码到脚本" 按钮

#### 4.6 设置模块

**功能**：配置工具的各项参数和设置。

**主要配置项**：
- **模板路径**：Controller 和 Task 脚本模板的存放路径
- **命名空间**：生成脚本的默认命名空间
- **作者信息**：生成脚本中的作者名称
- **文件后缀**：生成脚本的文件名后缀
- **输出路径**：生成脚本的默认输出目录

### 5. 高级用法

#### 5.1 自定义模板

您可以修改 Controller 和 Task 的模板文件来自定义生成脚本的结构：

1. 在设置模块中找到模板路径
2. 编辑 `UIControllerTemplate.cs` 和 `UITaskTemplate.cs` 文件
3. 使用占位符（如 `_NAMESPACE_`, `_CONTROLLER_` 等）定义模板结构

#### 5.2 批量操作

对于大型 UI 项目，您可以：

1. 使用相同的命名约定批量创建多个 Controller
2. 通过复制 JSON 配置文件快速设置相似的 UI 结构
3. 利用变量命名规则确保代码一致性

#### 5.3 版本控制集成

所有配置数据都以 JSON 格式保存，便于：

- 跟踪 UI 结构变更历史
- 团队协作时共享配置
- 回滚到之前的 UI 绑定状态

### 6. 常见问题解答

**Q: 为什么我无法选择某些组件？**
A: 确保您选择的是 Prefab 实例中的组件，而不是场景中的独立对象。组件必须属于您在基础模块中选择的 Prefab。

**Q: 生成的脚本路径不正确怎么办？**
A: 在设置模块中检查输出路径配置，确保路径指向正确的目录。

**Q: 如何处理组件路径变更？**
A: 工具会自动检测组件路径变更并提示您更新绑定。您也可以手动重新绑定受影响的组件。

**Q: 可以自定义组件类型吗？**
A: 是的，您可以通过修改模板和组件绑定逻辑来添加自定义组件类型的支持。

**Q: 如何解决变量名冲突？**
A: 工具会自动检测变量名冲突并提示您修改。您可以为冲突的变量指定自定义名称。
