# 钓具组装界面交互优化 - 功能需求文档

## 1. 简介

本文档旨在明确钓具组装（Tackle Assemble）界面的详细交互功能需求。目标是优化用户体验，提供一个清晰、流畅、功能明确的三状态（默认、自由观察、Slot特写）交互模型。

## 2. 功能需求列表

### 2.1. 视图状态定义

系统需要明确定义并管理以下三种核心视图状态：

| 状态ID | 状态名称 | 描述 |
| :--- | :--- | :--- |
| `Default` | **默认状态** | 用户进入界面时的初始状态，提供完整信息概览。 |
| `FreeObservation` | **自由观察状态** | 用户通过拖拽交互，自由旋转和观察3D钓具模型的细节。 |
| `SlotCloseup` | **配件槽特写状态** | 用户点击特定配件槽（Slot），系统提供该配件的近景特写或专门的交互界面。 |

### 2.2. `Default` (默认状态) 需求

- **FR-D1**: 界面必须同时展示三个核心视图元素：
    - 主要的钓具3D模型视图。
    - 钓组（BaitGroup）的放大镜视图（RenderTexture）。
    - 屏幕上叠加的所有可交互的配件槽（Slot）UI按钮。
- **FR-D2**: 在此状态下，所有Slot UI按钮必须是可点击的。
- **FR-D3**: 在此状态下，用户可以通过鼠标拖拽操作进入`自由观察状态`。
- **FR-D4**: 在此状态下，用户可以通过点击一个Slot UI按钮进入`配件槽特写状态`。

### 2.3. `FreeObservation` (自由观察状态) 需求

- **FR-FO1**: 进入此状态后，钓组放大镜视图必须被**隐藏**，以提供无遮挡的3D模型观察空间。
- **FR-FO2**: 交互方式必须遵循以下规则：
    - **水平拖拽**：围绕Y轴旋转钓具Actor本身。
    - **垂直拖拽**：围绕X轴旋转场景相机，实现俯仰观察。
- **FR-FO3**: Actor的水平旋转必须有角度限制（例如，左右各不超过90度），以防止模型因过长而穿出屏幕。
- **FR-FO4**: 用户松开鼠标拖拽后，系统必须自动平滑地返回到`默认状态`。
- **FR-FO5**: 返回`默认状态`时，钓具Actor的旋转角度必须自动平滑地归位到初始角度。
- **FR-FO6**: 返回`默认状态`时，钓组放大镜视图必须被重新**显示**。

### 2.4. `SlotCloseup` (配件槽特写状态) 需求

- **FR-SC1**: 系统必须能够区分不同类型的Slot，至少包括：
    - **`TackleSlot`**: 属于主钓具的配件槽，如鱼轮、握把等。
    - **`BaitGroupSlot`**: 属于钓组的配件槽，如鱼钩、铅坠等。
- **FR-SC2**: **点击`TackleSlot`**时：
    - 必须进入3D场景的特写模式。
    - 钓组放大镜视图必须被**隐藏**。
    - 场景相机必须平滑地移动和聚焦到被点击的配件槽的特定位置。
    - 必须提供一个明确的“返回”按钮，用于退出特写，返回`默认状态`。
- **FR-SC3**: **点击`BaitGroupSlot`**时：
    - 不得改变3D主场景的相机状态。
    - 钓组放大镜视图的UI元素（`RawImage`）必须在2D层面执行放大和居中动画，成为屏幕的主要交互内容。
    - 必须提供一个明确的“返回”或“关闭”机制，用于退出放大状态，恢复到`默认状态`的UI布局。
