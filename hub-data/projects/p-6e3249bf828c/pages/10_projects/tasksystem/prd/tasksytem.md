## 一 ## 系统功能

| 1.任务状态管理 |
| 1） | 未解锁：前置条件未满足，不可接取。 |
| 2） | 可接取：前置条件已满足，一般用于手动接取类任务，如出现在公告板上的任务，等待玩家操作。 |
| 3） | 进行中：玩家已接取并开始做任务，任务已经开始进行进度记录。 |
| 4） | 已达成（可领奖）：任务目标已完成，非自动领奖的任务提示可领奖。 |
| 5） | 已结束：任务已达成，且已领取奖励。 |
| 6） | 已失效：任务超时、丧失某些前置条件或被主动放弃，需要重置或销毁。 |
| *不是所有任务都有以上的全部状态，如，主线任务自动接取，则不会历经可接取状态；如某任务配置为自动领奖，则不会历经已达成状态。 |
| 本次修改 | 2.任务接取和领奖类型 |
| 1） | 接取类型：自动接取和手动接取 |
| ① | 自动接取：任务的前置条件满足后，自动进入进行中状态。 |
| ② | 手动接取：任务的前置条件满足后，进入可接取状态，待玩家手动接取后，进入进行中状态。 |
| 2） | 领奖类型：自动领奖和手动领奖 |
| ① | 自动领奖：任务达成后，自动领取奖励，任务直接进入已结束状态。 |
| ② | 手动领奖：任务达成后，进入已达成（可领奖）状态，需要玩家手动领取奖励后，才将状态更新至“已结束”。 |
| 3.事件监听 |
| 仅针对状态为“进行中”的任务进行事件监听： |
| 1） | 行为触发：游戏内玩家的各行为（如上鱼、买卖、乘船等）都可被封装成各个事件，行为触发时，事件被抛出。 |
| 2） | 事件抛出：系统抛出携带各式参数的事件。 |
| 3） | 参数过滤：任务系统收到事件，根据配置筛选出关注各个事件的任务，再根据配置筛选各任务关注的核心参数（check_params）。 |
| 4.链式任务和组式任务的处理 |
| 任务的衔接关系一般分为链式和组式，二者可以自由组合做出较为丰富的任务结构。 |
| 1） | 链式任务：一般用于主线，结构为任务A>>任务B>>任务C。 |
| 本次修改 | ① | 并行逻辑：游戏中可同时存在多条并行的链式主线。 |
| ② | 接取逻辑：链条中的首个任务（如任务A）需判断其前置条件（accept_cond_id）是否满足，若满足则自动接取。 |
| 后续任务在前一个任务“已结束”后自动接取，同时状态立刻更新为“进行中”。 |
| 任务A |
| 2） | 组式任务：结构为任务P（and/or） | >> | 任务B | 。 |
| 任务C |
| 5.进度记录 |
| 如核心参数符合配置需求，则根据目标值类型（value_type）更新对应任务的进度。 |
| 1） | 累加型：顾名思义。 |
| 示例：钓3条鲤鱼（0/3）。 |
| 2）单次型：检查极值是否满足目标值。 |
| 示例：钓1条重量在5kg以上的鲤鱼（0/5或0/1）。如果将5视作目标值，则进度记录需要体现极值的更新，如（1.234/5→2.8/5→3.66/5）。 |
| 3）集合型：检查某个集合中的所有元素是否被集齐。 |
| 示例：钓获所有体型的鲤鱼（0/5）。 |
| 本次修改 | 6.组队任务逻辑 |
| 针对配置了is_team_task=1的任务，玩家可选择组队完成，但同时也支持单人完成。组队任务遵循下列逻辑： |
| 1） | 共享范围 |
| 玩家必须处于同一队伍、同一地图、同一房间内。 |
| 2） | 进度累计 |
| ① | 任意一名满足共享范围条件的队友触发了组队任务关注的事件，队伍内所有接取了该任务且处于进行中状态的玩家，均获得相应任务进度累计。 |
| ② | 例：若队友A接取了该组队任务，但队友B没有接取该任务，队友B的行为同样可以为队友A的任务提供进度累计。 |
| 若队友A和B都接取了该组队任务，则队友A和B均可以为该任务提供进度累计。 |
| 3） | 结算逻辑 |
| ① | 任务的完成和领奖均只针对接取了该任务的玩家独立结算。 |
| ② | 例：队友A和B都接取了该组队任务，但队友B后接取，因此队友A的任务进度先达标，此时队友A的该任务可走结算逻辑并判定为已结束，但队友B的任务进行状态不受影响。 |
| 7.任务达成判定 |
| 当任务进度满足目标值需求时，若该任务配置为手动领奖，则任务的状态从“进行中”更新为“已达成”；若配置为自动领奖，则任务状态更新为“已结束”。 |
| 8.奖励发放 |
| 当任务达成后，该任务配置的奖励状态从“未领取”变为“可领取”，玩家可手动领取奖励。 |
| 1） | 自动领奖：任务状态直接从“进行中”更新为“已结束”，奖励自动发放至玩家仓库。 |
| 2） | 手动领奖：针对状态为“已达成”的任务，玩家需要主动交互领奖。 |
| *若某任务没有配置奖励，则该任务达成后，其状态也直接从“进行中”更新为“已结束”。 |
