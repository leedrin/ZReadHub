# 鱼系统——鱼市_系统功能


## 序 ## 概述

| 一、页签概述 |
| 当前页签主要描述鱼属性系统中用到的相关系统功能。 |
| 二、目录 |
| 1、新鲜度 |
| 2、单位显示规则 |
| 3、刷新规则 |

## 一 ## 新鲜度

| 1 | 以玩家上鱼的瞬间开始计算鱼的新鲜度 |
| 2 | 新鲜度以现实时间24小时的方式从100%衰减到0% |
| 3 | 新鲜度为0之后，鱼的单价按幼年体计算 |

## 二 ## 单位显示规则

| 1 | 鱼的体长和重量显示：单位自动进位（阈值1m/1kg/1t），最多保留4位有效数字，末尾多余小数位直接移除。(长度单位：cm、m；重量单位：g、kg、t） | 2025.12.5 |

## 三 ## 任务接取

| 1 | 鱼市任务的接取类型（accept_type）均配置为自动接取，部分有前置条件。 |

## 三 ## 刷新规则

| 1 | 当时间倒计时归0之后会重新刷新新的任务，新的任务按关卡id从鱼市任务池和对应的组别中抽出 |
| 2 | 新刷新的任务不会刷出现有的8个任务栏中相同的任务ID，包括自己。 |
| 3 | 当任务完成之后，任务进入待领取状态，且显示刷新时间。如刷新时间到了之后但玩家并未领取奖励，那么任务任然会刷新，奖励通过邮件的方式发送给玩家 | ..\通用系统\通用系统_邮件.xlsx |

## 四 ## 排序

| 1 | 根据排序条件调整优先选择的鱼 |
| 2 | 排序内容引用鱼市的规则，同时增加排序规则：价格和任务。根据售价进行排序。排序内容有：获得时间（默认），稀有度，重量，价格，任务 |
| 3 | 当玩家通过任务栏点击选中满足任务的鱼之后，排序会变为任务的降序，且进入多选状态自动选中 |
| 4 | 默认排序是获得时间排序 |
| 排序刷新 |
| 1 | 当前界面如果产生位置变动或物品增减，就都滚到最开始，相当于是页面刷新了。但是如果界面没有变动的话 就都保持在原来的位置 |
| 例如我在仓库划到底部查看物品，回来之后应该还是在原来的位置。鱼市卖鱼点击取消之后回来还是保持在原来的位置 |
| 排序相当于位置变动，所以就滚到最开始 |

## 五 ## 售卖

| 1 | 玩家通过售卖获得的货币会直接计算到玩家的货币栏中 |
| 2 | 玩家通过单选卖出则直接售出，如在多选状况下选择售出，则会弹出二次结算界面，即使只选了1个也会弹出 |

## 六 ## 鱼市的界面入口与关闭

| 1 | esc规则参考统一规则 | ..\通用系统\通用系统_操作快捷键规划.xlsx |
| 2 | 界面入口 | 场景交互 |
| a | 场景交互：通过和场景内的鱼市进行交互 |
| 3 | 关闭方式 |
| a | 界面关闭：点击界面右上角的关闭按钮 |
| b | ESC关闭 |
| 4 | 当点击售卖之后会弹出卖出确认界面，此时按esc和点击取消会返回鱼市界面。按Space会确认卖出 |
| 5 | 在结算界面点击确认卖出之后进行结算动画，此时无法点击esc的操作。结算结束之后返回鱼市允许使用esc |
| 卖出确认界面 |
