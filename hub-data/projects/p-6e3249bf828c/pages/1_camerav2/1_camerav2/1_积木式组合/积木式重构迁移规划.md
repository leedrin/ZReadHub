# 🧱 相机系统：积木式重构与旧模式迁移规划

## 1. 核心哲学：配置-状态-分发 (Config-State-Dispatch)

重构后的系统将彻底摒弃“一个业务一个类”的传统写法，转而采用“**通用容器 + 原子积木**”的架构：
*   **业务模式 (Mode)**: 仅作为 Prefab 容器，定义业务参数，并将输入/指令注入管道。
*   **相机状态 (CameraState)**: 唯一的物理真理，在管道中流动并被不断突变（Mutate）。
*   **功能模块 (Module)**: 承载单一数学逻辑的“加工厂”，只对 `CameraState` 负责。

---

## 2. 原子积木库设计 (Building Blocks Library)

通过对旧模式的解构，我们需要实现以下核心积木：

### 2.1 Body 阶段 (位置与轨道)
| 积木名称 | 对应旧模式功能 | 核心逻辑 |
| :--- | :--- | :--- |
| **PositionFollowModule** | SimpleFPS, FollowTPS | 简单的位置跟随，支持平滑。 |
| **OrbitTrackModule** | OrbitView, Observation | 基于 `ReferenceLookAt` 的球面坐标计算。 |
| **PathTrackModule** | PitchTrackFPS/TPS | 根据 Pitch 角度在自定义轨道（Track）上插值位置。 |
| **TackleInterpolationModule** | TackleObservation | 独有的三轨道（ZoomIn/Default/ZoomOut）插值系统。 |

### 2.2 Aim 阶段 (旋转与对齐)
| 积木名称 | 对应旧模式功能 | 核心逻辑 |
| :--- | :--- | :--- |
| **LookAtTargetModule** | FollowTPS, PitchTrackTPS | 使相机始终朝向 `ReferenceLookAt`。 |
| **InputRotationModule** | SimpleFPS, OrbitView | 将玩家 Look 输入转化为 `RawRotation`。 |
| **PitchCurveModifier** | PitchTrackFPS | 使用 AnimationCurve 根据 Pitch 修正旋转。 |

### 2.3 Noise/Offset 阶段 (修正与表现)
| 积木名称 | 对应旧模式功能 | 核心逻辑 |
| :--- | :--- | :--- |
| **HeadCompensationModule** | PitchTrackFPS | 模拟头部运动的物理补偿偏移。 |
| **CollisionModule** | OrbitView, FollowTPS | 射线检测并修正 `RawPosition` 防止穿墙。 |
| **CompositionModule** | 所有模式 | 突变 `ProjectionMatrix` 实现非中心构图。 |

### 2.4 Finalize 阶段 (覆盖与应用)
| 积木名称 | 对应旧模式功能 | 核心逻辑 |
| :--- | :--- | :--- |
| **CineDirectorOverride** | CineCameraMode | 完全接管状态，强制应用 `PlayableDirector` 的输出。 |

## 3. 旧模式迁移路径 (Migration Map)

通过“搭积木”复刻原有功能：

### 3.1 基础 FPS/TPS 组合
*   **SimpleFPS**: `PositionFollow` (Body) + `InputRotation` (Aim)
*   **FollowTPS**: `PositionFollow` (Body) + `LookAtTarget` (Aim) + `Collision` (Finalize)

### 3.2 轨道观察组合
*   **OrbitView**: `OrbitAutoFit` (Body 0) + `OrbitInput` (Body 5) + `OrbitFollow` (Body 10) + `Collision`
*   **Observation**: 在 OrbitView 基础上增加 `AutoReturnModule` (Body 15)

### 3.3 专项业务组合
*   **TackleObservation**: `TackleInterpolation` (Body) + `CloseupModule` (Body Override) + `LookAtTarget` (Aim)
*   **PitchTrackFPS**: `PathTrack` (Body) + `HeadCompensation` (Noise) + `PitchCurveModifier` (Aim)

---

## 4. 关键技术细节：指令与输入管道化

为了实现上述组合，必须完成以下底层重构：

### 4.1 CameraModuleContext 扩展
```csharp
public readonly struct CameraModuleContext {
    // 输入流
    public readonly IInputProvider m_input; 
    // 指令流 (Flags)
    public readonly bool m_resetRequested;
    public readonly bool m_autoFitRequested;
    public readonly float m_transitionDuration;
}
```

### 4.2 CameraModeComponent 基类增强
*   **输入缓冲**: 每一帧收集 `HandleRotation/Position` 的输入，存入缓冲区。
*   **指令注入**: `ResetState()` 不再调用模块，而是设置 `m_resetDirty = true`，在下一帧 `BuildModuleContext` 时注入。

---

## 5. 实施路线图

1.  **第一阶段 (Core)**: 扩展 `CameraState` (ReferenceLookAt) 和 `CameraModuleContext` (Flags)。
2.  **第二阶段 (Base Modules)**: 实现 `PositionFollow`, `InputRotation`, `LookAtTarget` 等原子模块。
3.  **第三阶段 (Complex Modules)**: 迁移 `Orbit` 和 `Track` 相关的复杂数学逻辑。
